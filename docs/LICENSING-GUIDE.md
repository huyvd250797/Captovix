# Captovix V1.29.1 — Hướng dẫn bản quyền

Hướng dẫn hiện hành nằm tại **[SERVERLESS-LICENSING.md](SERVERLESS-LICENSING.md)**.

Bản review chưa cấu hình URL/public key production nên chỉ chụp vùng. Làm theo hướng dẫn mới, dựng bản cấu hình và nghiệm thu Windows trước phát hành.
