# Captovix V1.7.0 — Shapes & Stroke Studio

9 hình kín, đường thẳng, mũi tên một/hai đầu với 4 kiểu đầu. Màu viền/nền và độ đậm độc lập, no outline/no fill, độ dày tùy nhập, nét liền/đứt/chấm/đứt–chấm, bo góc và ngôi sao cấu hình được. Đối tượng chọn, kéo, resize, đổi loại hình/kiểu nét, Undo/Redo, lưu và sửa tiếp.

3 preset mới, lưu mẫu đầy đủ; tùy chọn chỉ dùng preset cho nét mới. Schema 5 đọc 1–4, giữ backup sidecar cũ trước lần lưu đầu. Giữ capture pixel lẻ V1.6.1, chuyển ảnh V1.5.1, cấu hình updater và đường dẫn cài đặt.

Cross-build/test logic trên Linux. Chưa thực thi WPF/GDI/chuột/DPI/clipboard/installer/update trên Windows thật; chờ nghiệm thu. HDR/màu rộng chưa đánh giá. V1.8 tiếp theo: layer panel, khóa/ẩn/đổi tên, X/Y/W/H/góc xoay và cải thiện điều khiển nhiều đối tượng.
