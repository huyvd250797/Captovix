# Nghiệm thu Windows V1.46.4

Chạy trên Windows Sandbox hoặc máy test có thư viện riêng.

1. Cài mới và cài đè V1.46.3. Kiểm Start Menu có Captovix Recovery Center. Mở app và kiểm thư viện, KEY, thiết lập hiện có.
2. Mở Trung tâm từ menu Trợ giúp, sau đó thoát app cả ở khay. Ngắt mạng rồi bấm Thử lại. Kiểm thông báo kiểm tra cập nhật và xác nhận app mở được.
3. Thoát Captovix. Tạm đổi tên Captovix.dll trong current trên máy test. Mở Trung tâm từ Start Menu và kiểm báo lỗi, thử lại, và không báo đã khôi phục. Trả lại tên DLL sau test.
4. Cấu hình nguồn HTTPS thử nghiệm có bản stable cao hơn, với gói thực và ghi chú riêng. Bấm Thử lại, kiểm phiên bản đích, bấm Cập nhật & mở lại. Kiểm file sao lưu và phiên bản sau cài. Công cụ chỉ báo đã khôi phục khi màn hình chính mở.
5. Thử gói sai hash. Kiểm app không bị thay, công cụ báo lỗi. Thử để Captovix chạy khi bấm cập nhật. Công cụ yêu cầu đóng app trước.
6. Chỉ ghi manualAcceptance=PASS sau khi kiểm trực tiếp trên Windows.
