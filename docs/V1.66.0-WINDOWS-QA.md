Build/publish .NET 10 Windows x64. Run Ensure-MediaEngine.ps1 first or Build.cmd. Keep licensing config from the source. Do not reset user data.

## Timeline MP4

1. Record/import an MP4 with visible changing content and speech. Split twice, trim the middle, move segment 3 before 1, keep stable segment numbers. Export **Xuất timeline MP4**, reopen the single file, verify order and audio on every boundary.
2. Export the selected segment separately from a nonzero timeline offset. Verify annotations and sound use the selected segment's time window.
3. Repeat with source audio only, mic/system sidecars, no audio, mute/solo, music and fades. Add camera, crop/rotation, 16:9 / 9:16 / 1:1, Vietnamese callout and click effects. Compare preview/output.
4. Split many times at non-frame timestamps, include speed 0.5x / 2x and a 2-second hold. Check duration, frames and voice at start/middle/end. Cancel export; existing destination must survive and temporary directory must be removed.
5. Run VideoExportChecks with the pinned Windows FFmpeg; automated checks must pass. Linux run uses a Linux FFmpeg and cannot validate Windows codecs or the entire WinRT/WPF orchestration.

## Region modal / window preview

1. Choose Quay → Vùng chọn. Hover a modal, click suggested rectangle. Overlay must remain and Quay must be enabled. Resize/move selection, press Quay; verify fixed desktop pixels are recorded. Move/close the original modal: capture must not follow the HWND.
2. Repeat drag region, suggested non-modal region, Escape, Enter, 100% / 150% / 200% DPI, negative-coordinate second display. Still-photo click/release behavior must remain unchanged.
3. Choose Quay → Cửa sổ. Check previews/title, selection highlight, refresh, Enter/doubleclick/cancel. Resize/scroll picker; previews must not paint over footer. Close a source before confirm; refresh without recording the wrong process.
4. Open/close picker 50 times; check no accumulating DWM thumbnail handles and no background polling when closed. Test protected/blank previews; title still identifies the window.

## Library retention / Windows Recycle Bin

Use an isolated test library and copies of media. No production dates need changing.

1. Default disabled. Save 60 days then reopen Settings/restart. Data persists. Invalid, zero, fractional or negative values rejected.
2. With a test Windows clock/library: 01/11/2026 becomes eligible on 31/12/2026; 01/05/2026 is already expired on 20/11/2026 after enabling 60 days. Enabling at noon must not delete at noon; process at23:59.
3. Keep Captovix running in background across23:59. Verify only eligible entries disappear and their original byte data/edits are in a dated transaction folder in **Windows Recycle Bin**, with Captovix-recovery.json. Restore that folder and verify files. Manual delete/Restore still uses the separate app trash.
4. Test app closed at23:59: no service/task is installed, cleanup waits for a later23:59 while the app is running. Sleep across23:59: handle overdue timer on wake. While recording/exporting, postpone until idle without repeatedly scanning media.
5. A linked video source outside app remains. A source referenced by a kept video project must remain. Current captured source shared by multiple entries, retained camera/audio sources and update backup files must survive.
6. Lock a media file or deny recycling: rollback restores originals and library, report error, do not retry deletion continuously. End process before metadata commit and after metadata commit/before recycle: reopen app, verify original metadata/IDs/edits recover. End process after successful recycle/before journal removal: keep items removed, do not recreate ghosts.

This document is an acceptance checklist, not evidence these Windows runtime checks have executed.
