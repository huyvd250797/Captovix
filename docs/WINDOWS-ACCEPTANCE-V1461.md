# Nghiệm thu Windows V1.46.1

Trạng thái: chờ chạy trên Windows 10/11 x64.

1. Cài mới và cài đè V1.46.0. Kiểm icon trên Explorer, taskbar, khay, shortcut, About và bộ cài.
2. So bố cục menu, toolbar, thư viện dọc/ngang, canvas, thuộc tính và thanh trạng thái. Kiểm thứ tự toolbar đã cá nhân hóa.
3. Kiểm Sáng, Tối, Theo hệ thống. Đổi màu nhấn và màu/gradient riêng cho icon. Góc gập đổi màu, khung chụp trắng giữ tương phản.
4. Kiểm hover, focus, disable, viền popup/menu và nút Quay đỏ/chữ trắng. Thử DPI 100%, 125%, 150% và 200%.
5. Chạy BatchWindowsChecks và ScrollAppearanceWindowsChecks. Thử chụp, quay, OCR, Mockup, Undo/Redo, xuất ảnh và phím tắt trên app.
6. Chỉ ghi manualAcceptance=PASS sau khi có kết quả thực tế.
