# Changelog

## 0.1.0 — Capture Foundation

- One Editor with integrated source/audio/cursor/delay/FPS configuration.
- Region/window/display PNG and MP4 capture through Windows capture APIs.
- Mic + system loopback support, recording control bar and hotkeys.
- Physical pixel multi-monitor geometry, negative origins, DPI diagnostic report.
- Local history, thumbnail images, video playback, copy/export/import/rename/delete.
- Self-contained Windows x64 packaging, portable launcher and NSIS Setup.exe.
- Core geometry tests and explicit Windows validation checklist.

Not yet a Windows runtime-validated production release. See docs/VALIDATION.md.
